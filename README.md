# Vellura — Psicologia e Bem-estar

Landing page estática (HTML + CSS + ~4 KB de JS vanilla), sem frameworks nem build.

- Imagens em WebP, vídeo do hero recomprimido (H.264, 720p, sem áudio) e carregado só depois do `load`.
- Fonte Inter auto-hospedada (apenas o subset latin).
- Para alterar o número do WhatsApp, troque `5500000000000` em `index.html` e `assets/app.js`.

Rodar localmente: `python -m http.server` e abrir http://localhost:8000.
